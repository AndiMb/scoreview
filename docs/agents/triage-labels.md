# Triage-Labels

Die Skills sprechen von fünf kanonischen Triage-Rollen. Diese Datei bildet sie
auf die Labelnamen ab, die im Issue-Tracker dieses Repos tatsächlich benutzt
werden.

| Label in mattpocock/skills | Label in unserem Tracker | Bedeutung |
| -------------------------- | ------------------------ | --------- |
| `needs-triage`             | `needs-triage`           | Muss noch bewertet werden |
| `needs-info`               | `needs-info`             | Wartet auf Rückmeldung der meldenden Person |
| `ready-for-agent`          | `ready-for-agent`        | Vollständig beschrieben, ein Agent kann es allein umsetzen |
| `ready-for-human`          | `ready-for-human`        | Braucht eine menschliche Umsetzung |
| `wontfix`                  | `wontfix`                | Wird nicht bearbeitet |

Nennt ein Skill eine Rolle ("das AFK-taugliche Triage-Label setzen"), dann gilt
der Labelname aus der rechten Spalte.

Die rechte Spalte anpassen, falls im Tracker eine andere Vokabel eingeführt
wird - dann setzt `/triage` bestehende Labels statt Dubletten anzulegen.
